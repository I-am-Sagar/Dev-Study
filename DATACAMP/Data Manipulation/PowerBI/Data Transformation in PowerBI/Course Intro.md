**[Prerequisites: Data Preparation in Power BI]**

This course is part of these tracks:

* Data Analyst in Power BI

### Course Description

In this course, you’ll learn all about table transformations in Power BI. You’ll learn how to (un)pivot, transpose, and append tables. You’ll also get introduced to joins and discover when it makes sense to use them. Finally, you’ll gain power with custom columns, including how to use M language and the Advanced Editor, to help you be even more efficient in data preparation.

#### Chapter 1: Reshaping Data

In this chapter, you'll learn how to become a data plastic surgeon by restructuring and reshaping data in Power BI. You'll also stitch together data in different ways from various sources to enrich your analytical capabilities.

#### Chapter 2: Combining Data in Power Query

In this chapter, you'll learn stitch together data in different ways from various sources to enrich your analytical capabilities.

#### Chapter 3: Custom Columns

In this chapter, you’ll cover advanced features of Power Query, such as adding custom columns and custom conditionals.

#### Chapter 4: Advanced Editor

In the final chapter, you’ll learn to read and write M language, which allows for a more efficient way to do data transformations in Power Query.
